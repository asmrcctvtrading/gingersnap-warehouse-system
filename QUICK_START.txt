  "Connection refused":
    → Ctrl+Shift+P → Tasks: Run Task → "Start OmniRoute Server"
    → Wait 3-5 seconds
    → Try again: claude

  OmniRoute not auto-starting:
    → Check: omniroute status
    → Manual start: & 'C:\Users\Odyssey Jan Pascual\Desktop\Omniroute\Start OmniRoute.bat'

  Terminal doesn't show status:
    → Make sure you're using PowerShell (not cmd.exe)
    → Check: echo $PROFILE
    → Source profile: . $PROFILE
