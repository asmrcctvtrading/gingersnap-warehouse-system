  - Verify Claude Code v2.0+

PHASE 2: Add Ponytail Marketplace
  GUI Method:

    Enter: [PONYTAIL_REPOSITORY_URL]

  CLI Method:
    claude marketplace add ponytail <REPOSITORY_URL>

  GUI Method:
    Command Palette (Ctrl+Shift+P) > "Plugin Install" > "ponytail"

  CLI Method:
    claude plugin install ponytail

  - Run: claude plugin list | grep ponytail
  - Expected: "Ponytail (v1.0.0+) Status: active"
