# Ponytail Agent Configuration

This document provides automatic workspace guidance and coding standards for AI coding agents using the Ponytail plugin system.

## Agent Setup

This workspace is configured for multiple AI coding agents with the Ponytail plugin system. Ponytail provides consistent coding guidelines across:
- Claude Code
- GitHub Copilot
- Cursor
- Windsurf
- Cline
- Kimi Code
- OpenCode
- Gemini CLI
- And 15+ other agents

## Coding Guidelines

### Skills (6 Available)

Ponytail provides standardized skills at multiple intensity levels:
1. **lite** - Minimal guidelines, focus on core patterns
2. **full** - Standard guidelines with common best practices
3. **ultra** - Comprehensive guidelines with edge cases
4. **off** - No enforcement

### Project Standards

This project follows Ponytail's coding guidelines to ensure:
- Consistent code style across all agents
- Uniform error handling and logging
- Standard security practices
- Efficient resource management
- Clear documentation standards

## Agent Configuration

Each agent using Ponytail will:
1. Load this configuration automatically
2. Apply guidelines to all code generation
3. Follow the defined intensity level settings
4. Respect project-specific overrides
