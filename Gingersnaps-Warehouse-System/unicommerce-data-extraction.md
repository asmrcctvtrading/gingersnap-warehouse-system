## 3. TASK WORKFLOW STATES

### Picklist/Task-Level States

| State | Description | Next State |
|---|---|---|
| **CREATED** | Picklist created, awaiting assignment | PENDING |
| **PENDING** | Assigned to picker, waiting to start | IN_PROGRESS |
| **IN_PROGRESS** | Picker is actively picking items | COMPLETED |
| **COMPLETED** | All items picked, task finished | (Final) |

### Shipment-Level States (Related)

| State | Description | Next State |
|---|---|---|
| **PICKING** | Items being picked | PICKED |
| **PICKED** | All items picked at shipment level | DISPATCHED |
| **DISPATCHED** | Shipment ready to ship | (Final for picking) |
| **LOCATION_NOT_SERVICEABLE** | Special status (error/exception) | — |

### Item-Level States

- In Progress
- Cancellable
- Unfulfillable
- Dispatched
- Cancelled
- Returned
- Replaced
- Reshipped

## 7. KEY SYSTEM FINDINGS

### Architecture Notes
- **No dedicated Picker table** — Pickers are identified through the User management system
- **Multi-level task structure** — Picklist (task) > Shipment > Order Items
- **Status-driven workflow** — State machine approach with defined transitions
- **User-based tracking** — All actions tied to User IDs (Generated By, Picked By)

### Data Filtering & Queries
- Picklists can be filtered by status (CREATED, PENDING, IN_PROGRESS, COMPLETED)
- Users can be filtered by enabled status
- Department/Section tracking visible in user names (allocator, regularsection1) but not as separate DB field
- Timestamps implicit in status changes; explicit dates on Order creation and completion

### Export & Integration
- Export capability available through Tasks > Subscription export jobs
- Multiple task types exist (at least PUTAWAY_GATEPASS_ITEM identified)
- Potential for API integration (IDs use consistent prefixing: PT, LOCA, etc.)

### Missing/Inferred Data
- **Start time (picked_on)** — Not explicitly shown; inferred from status change to IN_PROGRESS
- **Completion time (completed_on)** — Not explicitly shown; inferred from status change to COMPLETED
- **Duration/TAT** — Calculated from Fulfillment TAT vs actual completion
- **Picker location/section** — Embedded in user name/role; not separate field

## 8. RECOMMENDED SCHEMA STRUCTURE FOR GINGERSNAPS

### Users Table (Pickers)
```sql
CREATE TABLE users (
  user_id INT PRIMARY KEY AUTO_INCREMENT,
  username VARCHAR(255) UNIQUE NOT NULL,
  email VARCHAR(255) UNIQUE NOT NULL,
  name VARCHAR(255) NOT NULL,
  phone VARCHAR(15),
  role VARCHAR(50),
  status ENUM('enabled', 'disabled') DEFAULT 'enabled',
  added_on DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_on DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

### Picklists Table (Tasks)
```sql
CREATE TABLE picklists (
  picklist_id INT PRIMARY KEY AUTO_INCREMENT,
  picklist_code VARCHAR(50) UNIQUE NOT NULL,
  shipment_id INT,
  generated_by_user_id INT NOT NULL,
  picked_by_user_id INT,
  status ENUM('CREATED', 'PENDING', 'IN_PROGRESS', 'COMPLETED') DEFAULT 'CREATED',
  task_type VARCHAR(100),
  created_date DATETIME DEFAULT CURRENT_TIMESTAMP,
  started_date DATETIME,
  completed_date DATETIME,
  no_of_items INT DEFAULT 0,
  FOREIGN KEY (generated_by_user_id) REFERENCES users(user_id),
  FOREIGN KEY (picked_by_user_id) REFERENCES users(user_id),
  KEY idx_status (status),
  KEY idx_picked_by (picked_by_user_id)
);
```

### Shipments Table
```sql
CREATE TABLE shipments (
  shipment_id INT PRIMARY KEY AUTO_INCREMENT,
  shipment_code VARCHAR(50) UNIQUE NOT NULL,
  order_id INT NOT NULL,
  status ENUM('PICKING', 'PICKED', 'DISPATCHED') DEFAULT 'PICKING',
  weight DECIMAL(10, 3),
  order_date DATETIME,
  fulfillment_tat DATETIME,
  created_on DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (order_id) REFERENCES orders(order_id),
  KEY idx_status (status)
);
```

### Picklist Items Table
```sql
CREATE TABLE picklist_items (
  item_id INT PRIMARY KEY AUTO_INCREMENT,
  picklist_id INT NOT NULL,
  shipment_id INT NOT NULL,
  sku VARCHAR(100) NOT NULL,
  quantity INT NOT NULL,
  warehouse_location VARCHAR(100),
  item_status ENUM('In Progress', 'Dispatched', 'Cancelled') DEFAULT 'In Progress',
  picked_date DATETIME,
  FOREIGN KEY (picklist_id) REFERENCES picklists(picklist_id),
  FOREIGN KEY (shipment_id) REFERENCES shipments(shipment_id),
  KEY idx_sku (sku)
);
```
