### Late Morning (10:30 AM–12:00 PM): Import to HubSpot

#### Task 1: Import CSV

(If you haven't already from Step 8 of HUBSPOT-FREE-SETUP.md)

1. Go to **HubSpot** → Contacts
2. Click **"Actions"** → **"Import contacts"**
3. Select `leads-day1to6.csv`
4. Map columns:
   - CSV "First Name" → HubSpot "First name"
   - CSV "Last Name" → HubSpot "Last name"
   - CSV "Phone" → HubSpot "Phone"
   - CSV "Email" → HubSpot "Email"
   - CSV "Service Interest" → HubSpot "Notes"
5. Click **"Import"**
6. Wait 1–2 minutes (green checkmark when done)

You should now see all Day 1–6 leads in HubSpot Contacts list!

#### Task 2: Create Deals for Hot Leads

Hot leads = people ready to move forward (expressed strong interest).

1. Go to **Deals**
2. For each hot lead, click **"+ Add deal"**
3. Fill in:
   - Deal name: "[Name] - [Service]"
   - Contact: [select from list]
   - Amount: [estimate, e.g., 32000]
   - Stage: "Awareness" (starting point)

Example:
- Juan Dela Cruz - 4 Camera Home: ₱32,000
- Maria Santos - Office System: ₱45,000
- Rosa Gonzales - Bakery CCTV: ₱38,000

**Rule:** Create deals only for leads who expressed real interest (avoid one-time browser clicks).

**Estimated time: 20 minutes (for 5–10 hot leads)**

### Afternoon (2:00–3:30 PM): First WhatsApp Sends

Now you send WhatsApp messages to your imported leads.

#### Task 1: Choose Template

Which template to send first?

- **New lead (cold/warm contact)?** → TEMPLATE 1 (Welcome)
- **They asked for price?** → Ask their service interest (respond to question)
- **Old lead (silent 2+ weeks)?** → TEMPLATE 5 (Re-engagement)

#### Task 2: Send WhatsApp Batch

Process:
1. Open WHATSAPP-SMS-TEMPLATES.md
2. Copy TEMPLATE 1 (Welcome)
3. For each lead:
   - Replace [Name], [service], [PHONE] with actual customer data
   - Open WhatsApp on your phone
   - Find customer in contacts (or create new contact)
   - Paste personalized message
   - Send
4. Log in HubSpot:
   - Find lead contact
   - Click "Log activity"
   - Add: "WhatsApp sent at [time] - Template 1"

#### Task 3: Target

Send to **10 hottest leads** today (takes ~15–20 minutes).

Rest of leads can wait until next week.

#### Task 4: Wait for Replies

Check WhatsApp inbox every 30 min. When customers reply:
1. Note their reply
2. Log in HubSpot: "Customer replied: [their message]"
3. Respond promptly (same day if possible)
4. Move deal to next stage if appropriate

**Estimated time: 1 hour**

## Monthly Tasks (Every 1st of Month)

### Review Requests Campaign
Send review requests to customers who installed 7+ days ago.

**Process:**
1. In HubSpot Deals, filter: "Stage = Won AND Date Won > 7 days ago"
2. For each customer, send:
   - **WhatsApp:** TEMPLATE 7 (Review request)
   - OR **Email:** Review request with Google + Facebook links
3. Log activity: "Review request sent"

**Target:** 3–5 new reviews per month

Run monthly special offer (e.g., "15% off this month")

**Process:**

## Troubleshooting

| Issue | Solution |
|---|---|
| Phone numbers formatted wrong | Add +63 at start, remove spaces/dashes |
| WhatsApp contact not found | Create new contact in WhatsApp app first |
| Customer replies in Spanish/Tagalog | Reply in same language (use Google Translate if needed) |
| HubSpot won't import CSV | Check: phone numbers have +63, no missing commas in names |
| Can't find someone's review link | Generate in Google Business or Facebook page settings |
| Forgot HubSpot password | Use "Forgot password" link on hubspot.com |
